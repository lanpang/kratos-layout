# Bug Tracking

按时间倒序记录项目里发现并修复、待修复或临时绕过的 bug。

## 条目格式

- **短描述**：用户可见症状或系统异常。
- **状态**：open / fixed / workaround。
- **根因**：一句话解释直接原因。
- **修复**：commit / PR / roadmap / API / ADR。
- **验证**：测试、smoke、日志证据。

新 bug 先写进 `Open`。修完后挪到 `Fixed`，最新在上。严重问题另写 `postmortems/`。
